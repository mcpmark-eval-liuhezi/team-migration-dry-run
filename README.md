# team-migration-dry-run
Throwaway repo for migration dry run

## Dry Run Notes

This repository is part of an end-to-end migration dry run performed before the
team's migration is signed off. The routine validated below worked end to end:

- Repository setup with an initialized README
- A manually triggered GitHub Actions workflow (`.github/workflows/dry-run.yml`)
  that runs one trivial job and uploads a `dry-run-report` artifact
- A branch, pull request, and review-draft flow
- Issue triage with GitHub Copilot assigned to an issue
